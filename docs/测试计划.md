# 电商平台测试计划

## 1. 项目概述

### 1.1 项目背景
本项目基于公开测试环境开展全流程测试实践：Web端以 SauceDemo 电商 Demo 站（https://www.saucedemo.com）为测试对象，覆盖登录、商品、购物车、结算全流程；接口端以 JSONPlaceholder 公开 REST API（https://jsonplaceholder.typicode.com）为测试对象，覆盖用户、帖子、待办等核心资源接口。

### 1.2 测试范围
| 模块 | 测试内容 | 测试类型 |
|------|----------|----------|
| 登录模块 | 正常/异常登录、Demo账号权限、登出 | 功能+自动化 |
| 商品模块 | 商品列表展示、排序、商品详情 | 功能+自动化 |
| 购物车模块 | 添加、移除、数量展示、清空 | 功能+自动化 |
| 结算模块 | 结算信息校验、概览核对、完成下单 | 功能+自动化 |
| 接口测试 | 用户/帖子/待办资源CRUD与参数校验 | 接口测试 |
| 性能测试 | 用户/帖子接口并发 | 性能测试 |

### 1.3 不在测试范围
- 注册功能（SauceDemo 为公开 Demo 站，无注册入口）
- 真实支付渠道扣款（Demo 站为模拟支付，不涉及真实资金）
- 订单管理后台（Demo 站无后台管理系统）

## 2. 测试策略

### 2.1 测试方法
- **黑盒测试**为主，结合白盒思路关注接口返回
- **功能测试**：手工执行，覆盖正常/异常/边界场景
- **接口测试**：Postman工具，自动化断言
- **自动化测试**：Selenium WebDriver + pytest，覆盖核心回归流程
- **性能测试**：JMeter并发压力测试

### 2.2 测试环境
| 环境 | 配置 | 地址 |
|------|------|------|
| Web测试环境 | saucedemo公开测试环境 | https://www.saucedemo.com |
| API测试环境 | jsonplaceholder公开API | https://jsonplaceholder.typicode.com |
| 性能测试环境 | 同上 | 同上 |

### 2.3 准入准出标准
**准入标准：**
- 测试环境（saucedemo / jsonplaceholder）可正常访问，冒烟测试通过
- 测试范围与用例设计完成评审
- 相关接口文档（JSONPlaceholder API 说明）确认

**准出标准：**
- 功能测试用例执行率100%，通过率≥95%
- 严重及以上缺陷全部修复并验证通过
- 接口测试覆盖率≥90%
- 性能指标达到预期（100并发下错误率<1%）
- 测试总结报告输出完成

## 4. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 需求变更频繁 | 用例返工 | 锁定核心需求，变更走变更流程 |
| 测试环境不稳定 | 执行阻塞 | 提前准备环境检查清单，问题及时反馈 |
| 自动化脚本维护成本高 | 进度延迟 | 只自动化核心回归流程，PO模式降低维护成本 |
| 性能测试环境与生产差异大 | 结果不准 | 报告中注明环境差异，结果仅供参考 |
